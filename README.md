# Portfolio – Khadidja Ahmat Hassan

Mon portfolio personnel (React + Tailwind CSS).

Structure inspirée d'un portfolio open source, dont l'auteur a donné son accord ; contenu, design et code adaptés par mes soins.

## Lancer en local

```bash
npm install
npm start
```

## Construire

```bash
npm run build
```

Déploiement : Vercel (framework « Create React App »).
